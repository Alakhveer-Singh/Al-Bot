FAQ

Good questions.

Which AI does it use?

You choose. Orate works with Claude, OpenAI, Gemini, Mistral, Llama (via Groq) and DeepSeek. One is active at a time, and you can switch whenever you like.

Do I need my own API key?

Yes. You add an API key from the provider you pick, so the AI usage is billed to your own account with that provider. Agencies can use a separate key for each client.

Will it make things up?

It is built to answer only from your site's content: your pages, posts, the extra pages you add and the files you upload. When something isn't covered, it says so instead of guessing, and the question is flagged in Analytics so you can add the answer.

Does it slow my site down?

The chat is a small script on the page, and the AI is only called when a visitor sends a message. It is built to work alongside caching plugins and CDNs such as WP Rocket and Cloudflare.

Can I use it for client sites?

Yes. Orate is made for agencies too: unlimited sites, white-label branding, and a separate API key for each client.

Is visitor data private?

Leads and chat analytics are saved in your own WordPress database. Visitor messages are sent to the AI provider you chose so it can reply. Your content and instructions stay on your server and are never sent to the visitor's browser.
